# Okie Dokie releases

Installers for Okie Dokie, a meeting notepad that keeps your notes on your computer. Download the latest version from the [Releases page](https://github.com/np123-glitch/okiedokie-releases/releases/latest).

## Mac

- Needs a Mac with Apple silicon (M1 or later) and macOS 14.2 or newer.
- Open the `.dmg` and drag Okie Dokie to Applications.
- The app isn't notarized by Apple yet, so macOS may block it the first time. Right-click Okie Dokie in Applications and choose **Open**.

## Windows

- Needs Windows 10 or 11 on a 64-bit PC.
- Run the `.exe` installer. It installs Okie Dokie for your user account only, so you don't need admin rights.
- The installer isn't code-signed yet, so Windows SmartScreen may warn you before it runs. Choose **More info**, then **Run anyway**.
- Windows has no on-device transcription yet, so you'll need to connect a transcription provider, such as OpenAI, Deepgram or AssemblyAI, in Settings.

This repository only holds installers. Okie Dokie is closed source.
